# UI 动效 PNG 图层素材

[下载四页 PNG 图层包](https://github.com/xinyicheng0219-cell/UIKT/raw/refs/heads/main/UI_PNG_Layers.zip)

压缩包约 13 MB，包含 4 页素材、101 个独立 PNG 图层、图集预览、图层清单和使用说明。

| 页面 | 图层数量 |
| --- | ---: |

**素材为依据截图生成的 AI 重建素材后拆层，并非原截图逐像素抠取。** 文字、人物、背景、比例和纹理可能与原图存在差异。遮挡区域为补绘，图层需要参照原图重新排版。人物为整体图层，未拆分关节或衣服。PNG 不支持多图层编辑，所以每一层独立存为一个 PNG。
